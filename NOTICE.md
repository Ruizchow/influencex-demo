# Project provenance

This repository is a downstream demo and deployment edition of
https://github.com/oratis/influencex, originally obtained in November 2026.
It was imported as a source snapshot, not created through GitHub's fork button;
GitHub therefore may not display an upstream fork relationship. The exact upstream
snapshot commit was not recorded. We do not claim the inherited implementation as
original work by this repository's maintainer.

Copyright (c) 2026 InfluenceX Contributors. The original MIT license is preserved
verbatim in LICENSE.

This edition is maintained by Ruizchow. Its additions include Render Free deployment
configuration, same-origin CORS handling for deployment, root-path hosting,
Zirui UI branding, local setup tooling, and bilingual project documentation.

Third-party APIs and platforms are separate services. This project is not affiliated
with or endorsed by those services. Their credentials are not bundled.
