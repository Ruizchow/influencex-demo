# Roadmap

These are proposed improvements for this downstream edition, not shipped promises.

## Available now

- Creator/campaign workspace, pipeline and content calendar UI.
- Provider-dependent discovery, AI, email and publishing integrations.
- Render Blueprint, local SQLite setup and Docker deployment.
- English and Chinese project documentation.

## Next

- [ ] A public read-only sandbox that works without an invite and cannot send emails.
- [ ] A clearer connection checklist showing which features need credentials.
- [ ] A richer seeded walkthrough from creator shortlist to campaign reporting.
- [ ] Persistent-storage deployment examples and backup/restore instructions.
- [ ] A short product walkthrough and refreshed desktop/mobile screenshots.

## Community ideas

- [ ] Improve creator application intake and review.
- [ ] Expand connector tests using recorded or mocked provider responses.
- [ ] Accessibility and mobile-layout improvements.
